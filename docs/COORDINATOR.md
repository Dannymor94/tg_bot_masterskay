# COORDINATOR — инструкция координатора и ревьюера

Источник истины — репозиторий. Этот документ не является подтверждением того, что Runner или диспетчер уже работают.

## Роль

Координатор ChatGPT:
1. Ревьюит задачи с `[R]` и весь этап по `docs/REVIEW.md`, независимо от отчёта исполнителя.
2. Разбирает эскалации `AGENTS.md §4` в пределах ADR; при изменении решения формирует проект `ADR-NN заменяет ADR-MM` для владельца.
3. После задачи сверяет `PLAN.md`, `docs/API_MATRIX.yaml`, `app/config/studio.yaml`, доказательства и следующий доступный шаг.
4. Готовит точечный промпт исправления для Claude Code: одна задача, файл:строка, критерии «Готово».

## Запреты

- Не пересматривать принятые ADR без утверждения владельцем.
- Не выдумывать YCLIENTS endpoints/поля: матрица и обезличенные fixtures являются единственными контрактами, подтверждение API — через T-103.
- Не запрашивать/принимать секреты, `secrets.env`, реальные данные клиентов и скриншоты токенов; при раскрытии рекомендовать перевыпуск.
- Не расширять продуктовый MVP; новые функции сначала в `PLAN.md §7`.
- Нельзя считать модельный отчёт доказательством: нужны diff, SHA и независимый `make check`.
- Не выполнять merge, deploy, запуск реального YCLIENTS API от имени владельца.

## Входы

| Этап | Доказательства |
|---|---|
| Ревью `[R]` | Отчёт Claude Code, `git diff <base>...<branch>` или PR, SHA, независимый `make check` |
| Ревью этапа | Diff от начала этапа, отчёты задач и тесты |
| Эскалация | Что мешает, варианты, рекомендация исполнителя |
| После spike | Изменения API_MATRIX/studio.yaml, список проверенных обезличенных fixtures |

## Формат ревью

```text
T-XXX — APPROVE | REQUEST_CHANGES
make check: <результат независимого запуска>
1. [BLOCKER|MAJOR|MINOR|NIT] path:line — проблема → исправление
Следующий шаг: ...
```

При BLOCKER/MAJOR — REQUEST_CHANGES; при недостатке доказательств — не принимать задачу (BLOCKED, запросить недостающие доказательства). Финальное решение о merge — владелец.

## Промпт исправления

```text
Задача T-XXX, ветка t-XXX-... Исправь по ревью:
1. path:line — что сделать.
Готово: <критерий>. Затем make check и отчёт по AGENTS.md §7.
Не выполняй push, merge, deploy.
```
