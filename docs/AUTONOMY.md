# AUTONOMY — граница проекта и внешней оркестрации

**Решение владельца:** Runner, GPT-ревью и диспетчер не разрабатываются в `tg_bot_masterskay`; они относятся к общей системе управления агентами для разных репозиториев. Задачи T-106/T-107/T-108 удалены из `PLAN.md` по ADR-23, а не объявлены завершёнными.

## Сейчас

Диспетчера и Runner пока нет. Владелец вручную запускает Claude Code в локальном клоне. Исполнитель берёт конкретную задачу `PLAN.md`, работает в отдельной ветке/worktree, запускает тесты, предоставляет diff и отчёт. Координатор проверяет задачи с `[R]` и этапы по `docs/REVIEW.md`. Merge/deploy только владелец.

## Будущий внешний диспетчер (не задача этого репозитория)

Может читать `PLAN.md`, `AGENTS.md`, `docs/REVIEW.md` и PR; запускать агентов, запускать проверки и передавать результаты на независимое ревью. Он должен уважать владельческий контроль merge/deploy, запрет на секреты и реальные данные, зависимости задач и неизменяемые ADR.

## Сейчас для продукта

T-001 (человек) и T-101 (агент) могут стартовать параллельно. После T-101 — T-102 и T-105 в независимых ветках. T-103 выполняется только после T-001 и T-102. Код из `scaffolds/` является предложенными исходниками и не означает, что зависимые задачи реализованы.

См. `docs/WORK_PACKAGES.md` и `docs/CONTRACTS.md`.
