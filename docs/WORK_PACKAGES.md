# WORK_PACKAGES — параллельные потоки без изменения статусов

Истинные статусы/зависимости — только `PLAN.md`; этот файл — карта разделения файлов и интеграции.

| Волна | Независимые задачи после завершения зависимостей | Ограничение |
|---|---|---|
| 0 | T-001 (человек), T-101 (Claude Code) | Нет диспетчера; запуск вручную |
| 1 | T-102 (YCLIENTS адаптер), T-105 (outbox/jobs), T-106 (Runner) | После T-101, отдельные ветки и worktree |
| 2 | T-103 (spike после T-001/T-102), T-201 (RBAC после T-105), T-107 (review после T-106) | Реальный spike только владелец |
| 3 | T-104 (domain+sync), T-203 (задачи), T-108 (диспетчер) | Контракты фиксированы и проверены |
| 4 | Клиенты, преподаватели, рассылки, пустые окна | Строго по индивидуальным зависимостям в PLAN |
| 5 | Интеграция и пилоты | Merge/deploy только владелец |

Общий `PLAN.md` обновляется только в ветке задачи; одновременные изменения разрешаются интегратором, без автоматического merge. Не назначать двум агентам один и тот же файл. До T-108 назначения производит человек.
