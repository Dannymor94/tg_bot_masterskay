# RUNBOOK — запуск, резервное копирование, восстановление

**Статус: шаблон для T-204. Не является инструкцией к уже развёрнутому сервису.**

После приёмки T-204 заполнить проверенными командами:
- установка Docker Compose и настройка одного сервиса на VPS в Германии;
- секреты вне репозитория с `chmod 600`;
- запуск, остановка, `make health`, журналирование без персональных данных;
- ежедневный `sqlite3 .backup`, ротация 14 дней;
- проверенное восстановление в отдельном каталоге;
- перевыпуск токенов, инциденты, ручной rollback;
- передача оператору результатов недельного пилота.

Ничего из перечисленного пока не считается реализованным или проверенным.
